# ДАЙДЖЕСТ ОЦЕНКИ ВАКАНСИЙ (v3.0 — сжатый)
Кандидат: Сверинов Александр Григорьевич.

## 1. ВЕСА, ФОРМУЛА И ПОРОГИ
- **Веса:** 8/5/3/2/1 (5 групп); 13/8/5/3/2/1 (6 групп); 21/13/8/5/3/2/1 (7 групп).
- **Формула:** Σ(вес × match) / Σ(весов) × 100%.
- **Пороги:** 95+ идеально, 85–94 отлично, 75–84 хорошо, 60–74 средне, 40–59 слабо, <40 не подаваться.
- **Правило среднего:** Если группа требований содержит перечисление (например, «опыт в CX/процессах/CRM/трансформации»), оценивай каждое подтребование отдельно и бери **среднее**, а не максимум.

## 2. ЖЁСТКИЕ ФИЛЬТРЫ (suitable=false)
- **Level 1 (отсекающие):** Если match < 0.7 и требование не является «плюсом»/soft-скиллом → `suitable=false`.
- **Банк/Финтех:** Если банк указан как «преимущество» — не отсекать (подаваться). Если «обязательно» — отсекать. (Пример: МТС Банк Платёжная — да; МТС Банк Центр сопровождения — нет).
- **Исполнительские роли (PMO, Release Manager, Project Controller):** Не использовать маркеры Lead/Head (450 млн, 28+15, 30→280). Оценивать по реестрам, отчётности, метрикам, Excel, трекерам.

## 3. ГРЕЙДИРОВАНИЕ И ЦИФРЫ (Критично!)
**Однозначные маркеры Lead/Head (только для senior+/Lead):**
- Бюджет 450 млн руб./год.
- 28 прямых + 15–25 непрямых подчинённых.
- Масштабирование команды 30 → 280 человек.

**НЕ маркеры Lead/Head (могут быть на middle):**
- Создание методцентра / PMO с нуля.
- Управление портфелем (5 подсистем в составе 19).
- ПФА и защита инвестиций (ближе к начальному senior).
- Курирование младшего PM.

**Универсальные цифры (можно везде):**
- SLA 98%+, 8000+ пользователей.
- 357 ЗНИ (все выполнены!).
- Конверсия +18%, CTR +25%, вовлеченность +27%.
- TTM −4–5 дней.
- 800+ задач (только ЭЛАР!), 22 источника (Роспатент).
- 5000+ (Directum), 1500+ (ProMIS).
- 87 сайтов, 5 подсистем в составе 19.
- Точность бюджета ±10% (для чётких границ). Для betting/iGaming — ±7%.

**Фактические привязки (НЕ ПУТАТЬ!):**
- 800+ задач = ЭЛАР (не ГАС!).
- TTM −4–5 дней = ГАС «Выборы» (не Frontier!).
- 357 ЗНИ = ГАС «Выборы» (все выполнены!).
- NoSQL (Elasticsearch, MongoDB) = «работал в задачах поддержки», не «владею». Реляционные (PostgreSQL, Oracle) — указывать первыми.
- TCO/ROI — есть в профиле, но не выпячивать. P&L, unit-экономика, маржинальность — ЗАПРЕЩЕНЫ.
- Directum = ЭДО/документооборот.
